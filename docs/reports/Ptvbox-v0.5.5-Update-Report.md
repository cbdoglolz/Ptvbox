# Ptvbox 0.5.5 本地交付

版本0.5.5 / versionCode 12。横屏ATV APK，兼容遥控器、鼠标和触摸；不是原生手机UI版。未上传、未发布、未发送企业微信消息，未连接真实机顶盒。D:/tvboxwin仅只读参考，没有改动Windows PCBOX。

## 本版完成

- [x] 集数横排先占位：网络资料未返回时立即出现占位卡；取得真实季集数量后逐步替换成编号卡片，随后填入剧照、简介、评分与首播日期。没有真实集数时不伪造“6集”，占位不代表集数。
- [x] 按作品/季缓存完整单集资料，重开时先显示缓存并刷新；数据库、网络和磁盘工作在IO线程，卡片绘制只消费状态。切季/切作品取消旧请求，按单集编号保持横排条目身份。
- [x] 单集简介恢复，统一264×306dp卡片。简介下方同一横条均分收藏和观看状态按钮，保留绿勾/紫眼/粉心。删除独立播放/三角播放按钮；点击卡片正文直接播放对应单集，收藏与状态另行操作。
- [x] 演员/导演与出品方/播出平台打开独立作品页，使用常规海报墙及双评分、中文海报缓存和TV焦点。出品方同时查询电影/剧集，可继续加载；演员页展示参与作品。
- [x] 导航保持完整返回链：原作品 → 演员/出品方页 → 另一作品，返回先回人物/公司，再回原作品详情；已有详情滚动位置由页面状态保留。应用内浏览不停止当前播放。
- [x] 豆瓣搜索更换为公开综合搜索的subjects分组和综合联想cards解析；只接受电影/剧集条目及可信subject ID，不把帖子、人物、书籍或联想词当影片。候选去重并保持正确作品类型。
- [x] 自动匹配保留年份、续集编号、季数和唯一性检查；对片名/原名不直接相同的候选，有限补查真实别名后再判断。不用“相似”把4误配成5，也不自动覆盖手动清除或指定的关联。中文人物名补查TMDB真实别名，拒绝无法唯一确认的同名人。
- [x] 匹配缓存增加算法签名：旧的失败关联重新检查，先保留已有海报，避免必须等24小时才恢复。手动清除和已指定ID仍优先，不以旧评分覆盖新的手动选择。
- [x] 搜索页依照参考改为左中右三栏：左侧历史与清空；中间搜索源、输入框、搜索/清空、远程/中文/语音输入和6列字母数字符号矩阵；右侧默认热门推荐，输入后显示联想，搜索后显示海报结果。
- [x] A-Z、0-9、符号、空格与删除完整输入；删除按Unicode码点处理。进入空搜索页焦点优先落到字母区，新增“中文输入”主动打开设备系统输入法。语音仍使用设备的语音服务。
- [x] 在线联想接入爱奇艺公开建议服务，中文、英文、拼音首字母结合本机片库；350ms防抖、取消旧词请求、有限缓存和离线回退。只使用名字，不信任联想接口可能错误的年份、资源ID或评分。
- [x] 热门区为豆瓣近期热门电影、剧集与综艺，界面注明不代表真实搜索量排名；6小时缓存。不是硬编码截图中的旧片名。
- [x] 保留影视资料、豆瓣、TMDB、全部资源站或指定站点搜索选项；联想不扫描100个站点。资源站模式先从首字母联想选完整片名再搜，避免向所有站点发送无法理解的缩写。资料模式可有限展开首字母候选，后提交的搜索不会被旧请求覆盖。

## 豆瓣故障根因

本机及模拟器复现：原`movie.douban.com/j/subject_suggest`对《玩具总动员5》返回200但内容为`[]`；原`rexxar/api/v2/search/movie`返回403，旧实现吞掉错误后没有候选进入匹配层。不能仅调模糊匹配阈值解决。

本轮公开综合搜索返回豆瓣ID **36238849**、2026年、评分及人数；新解析可正确读取subjects里的target类型和ID，并以综合联想补充。实测自动关联到此ID，评分8.0、当次138660人（实时数据会变化）。旧失败评分缓存也会因算法签名更新重新检查，不清空用户配置。

联想查询`WJZDY`实际返回24条名称，包括玩具总动员系列。服务的某个建议把5的year写成2010，因此严格只采纳联想片名，再用豆瓣/TMDB获取正式作品资料。
