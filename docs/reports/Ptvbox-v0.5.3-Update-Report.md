# Ptvbox 0.5.3 本地交付

版本0.5.3，versionCode 10。交付支持遥控器、触摸和鼠标的ATV APK，不是原生手机界面版。未上传、未发布、未发送企业微信消息，未连接真实机顶盒。

## 本版完成

- [x] 首页海报卡片下固定普通片名；横幅保留艺术字，无可用图片时才回退文字。0.5.2改错了位置，本轮修正实现及历史记录。
- [x] 横幅8秒倒计时、自动换片、420ms滑动淡入动画；移出可见区停止轮播。显示简介、年份/类型和最多4名主演，缺失人物不编造。
- [x] Ptvbox换设备的密码加密备份：全部已保存服务凭据、链接/订阅、站点开关/优先级、手动评分关联、收藏与观看状态、单集标记、毫秒级进度、音频和字幕设置。补上原白名单漏掉的动态直播续看凭据。
- [x] AES-GCM及PBKDF2-HMAC-SHA256保护备份，密码至少8字符；新设备使用自己的Keystore重新加密。默认合并缺少记录、保留现有设置和较新进度；可明确选择替换配置/凭据，不清空收藏与观看记录。无效字段/附件在合并前拒绝。
- [x] 最近使用的字幕内容/选择/偏移一同迁移，最多8MB；超限未包含数量在预览说明，仍可重新下载。弹幕派生缓存不迁移，避免挡住配置备份。
- [x] SubDL、ASSRT、OpenSubtitles搜索/字幕包/下载实现。优先TMDB/IMDb，再用片名与别名，按年份和季集过滤，拒绝明确冲突季集、2045/ARISE及非本片幕后版本。
- [x] CC直接查看紫色结果数量、字幕包文件及上次使用标记。支持ZIP、SRT/ASS/SSA/VTT、UTF-8/UTF-16/GB18030、本地导入，下载和加载均提示结果。
- [x] 搜索在关闭面板后继续，右上角紫框缓慢闪动；结束提示保留7秒，隐藏控制后仍可见，与其他提示错开。
- [x] 紧凑字幕弹窗分结果/样式/校时，40%不透明背景并取消系统额外压暗。中英示例实时变化，可调字号/字体/粗体/颜色/背景/透明度。外部字幕独立绘制，调整不重开视频；内嵌轨道继续由Media3处理。
- [x] 外部字幕提前/延后0.5秒、重置或点某句对准当前画面；按作品、季和集记忆，续播自动恢复。
- [x] OpenSubtitles区分搜索、登录、账号信息、下载链接和文件CDN错误；明确User-Agent、HTTP/1.1、受信base_url、双认证和真正file_id。CDN不带服务凭据，不自动重复消耗额度的POST，显示HTTP状态和Retry-After，错误不回显认证信息。
- [x] 弹幕按作品/年份/季集自动匹配，歧义手动确认；支持弹弹play兼容服务、自有官方凭据、公共中继及B站正片回退。滚动/顶端/底端、字号/透明度/密度/速度/偏移、本地XML/JSON及一天缓存已实现。不借用他人开发者凭据。

## 操作位置

备份：设置 → 隐私与数据 → 备份与还原 → 输入备份密码 → 创建文件或打开文件预览 → 选择合并方式并确认。使用系统文档选择器；缺少选择器的电视需要安装支持文档存储的文件应用。本轮未另建手机网页备份入口。

字幕：播放页CC；服务凭据在设置 → 字幕服务，也可用现有局域网扫码配置。弹幕：底部弹幕图标。

## 本轮验证

- 77项JVM回归通过，包括格式/编码/ZIP、季集/版本冲突、XML实体拒绝、输入大小和错误隐私。
- 隔离模拟器13项字幕HTTP与迁移契约通过：三个服务、字幕包、file_id、base_url/认证、CDN不带凭据、503阶段与不重复POST、动态凭据及数据迁移、错误密码/附件/字段拒绝。
- HTTPS配置8项、旧数据与备份12项回归通过。受控HTTP没有使用用户真实字幕服务账号。
- BlueStacks实际验证横幅艺术字、简介/类型/演员、倒计时/换片；本地字幕显示、样式预览、上次字幕及0.5秒偏移恢复。
- 公共弹幕服务带v2参数返回HTTP400；移除该服务不支持的参数后读取正常。首次《葬送的芙莉莲》第1集有两个同名候选，手动确认加载7323条，再次进入自动恢复缓存。
- 进一步播放真实《葬送的芙莉莲》第1集，HDHUB Stremio实际1080P出画面，同时绘制7323条库中的当前弹幕。`real-anime-test.txt`及`real-anime.png`是本轮证据；不以本地测试片冒充真实动画实播。
- Window.FrameMetrics采样：BlueStacks 8.2秒倒计时和一次自动切换，493帧，P95约18.97ms。回调约60次/秒不等于通过严格16.67ms预算；本轮严格稳定60fps未达标，原始数据保留于`ui-result.json`。
- 双APK原签名、Android8/API26、非debuggable、正确ABI、包内无私人链接/凭据/模块JAR/QA代码、默认32站未变均通过审计。
- Release覆盖安装后仍有原TMDB凭据与85站；安装包哈希与交付ARM包一致，未卸载或清数据。
- D:/tvboxwin只读参考的333份源码哈希均未变化，未修改PCBOX代码或配置。

证据位于`artifacts/qa-0.5.3`：`build-tests.txt`、`contracts-test.txt`、`tls-regression.txt`、`data-regression.txt`、`ui-test.txt`、`ui-result.json`、`real-anime-test.txt`、截图、`package-audit.json`、`release-install-check.json`、`pc-readonly-check.json`与源码变更清单。
