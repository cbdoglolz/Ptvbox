# Ptvbox 0.5.7 交付报告

版本：`0.5.7` / versionCode 14  
日期：2026年11月24日  
构建类型：横屏 ATV APK，兼容遥控器、鼠标和触摸  
交付范围：本地签名 APK 与测试记录；未上传、未发布 Release、未发送企业微信消息

## 本版完成

### 导航与首页

- [x] 左上角品牌改为只读区域：Ptvbox Logo、名称和当前版本号上下排列。
- [x] Home 按钮放在品牌区域下方；“返回播放”位于 Home 下方，触摸高度扩大到 56dp。
- [x] 删除内容区顶部的重复 Ptvbox Logo，豆瓣/Netflix/TMDB 页面上方不再出现重复品牌行。
- [x] 删除左侧“资源（高级）”导航项。

### 作品详情

- [x] 横幅背景改为覆盖整个右侧内容区的持久半虚化背景，随详情页滚动保持存在。
- [x] 艺术字片名、简介、分类和主演信息位于首屏，无需遥控器向上移动才能看到。
- [x] 豆瓣、TMDB 评分、评分人数、手动匹配和清除匹配压缩到同一行。
- [x] 手动匹配和清除匹配改为铅笔、清除图标，始终可用。
- [x] 详情分类标签继续支持一键筛选，英文地区和类型名显示为中文。
- [x] 未配置 TMDB Key 时，豆瓣详情仍读取演职人员、头像、免费相似推荐。
- [x] 豆瓣人物页改用官方 `celebrity/{id}/works` 数据，支持分页作品墙。

### 播放器

- [x] 控制层隐藏且没有按钮获得焦点时，确认键单击切换播放/暂停；暂停后仍可直接再按确认恢复，不必点击播放箭头。
- [x] 删除播放器顶部“返回原页面”按钮，统一由 BACK 分层返回。
- [x] 删除“更多设置”入口。
- [x] 播放器顶部显示艺术字片名、第几季、第几集和当前集标题。
- [x] 左右长按改为持续预览跳转：单击为 5 秒，按住 5 秒后进入 1 分钟递进，继续按住进入 5 分钟递进；松开时正式跳转。
- [x] 时间预览显示当前时间/总时长，确认时间轴不再一格一格移动。
- [x] 右下角原全屏按钮改为系统小窗；手机支持时进入 Picture-in-Picture，电视不支持时显示限制提示。
- [x] 播放器扫描期间不再显示插件广告过滤、扫码观看等噪声提示。

### 直播与历史

- [x] 直播详情页删除返回按钮，继续使用遥控器/系统 BACK。
- [x] 观看历史卡片缩小到 118dp 栅格。
- [x] 历史卡片左上角显示本地日期时间，底部保留单集和进度。
- [x] 长按历史卡片进入多选；右上角垃圾桶在选中状态删除选中项，在未选中状态提示清空全部历史。
- [x] 删除历史只影响播放进度；收藏和已看/在看/想看状态保留。

### 动画

- [x] 动画页左侧增加季度新番、近期热播、你可能也喜欢、动画搜索四个入口。
- [x] 年份支持 `-5`、`-1`、`+1`、`+5`，并提供 2017、2020、2023、2024、2025、2026 快速入口。
- [x] 动画搜索支持中文、日文原名和英文名，不再只按年份和季度查询。
- [x] 动漫海报和评分缓存继续沿用本地缓存；匹配签名加入片名、原名、别名和季数，旧失败缓存会自动失效。
- [x] Bangumi 补充中文名、别名、海报、评分、标签和简介，使后续 TMDB/豆瓣匹配可使用更多别名。

### 站点与网络

- [x] HDHUB Stremio API 和媒体请求使用独立直连客户端。
- [x] 即使配置一个不可用代理，HDHUB 仍可直接读取 18 条线路并出首帧。
