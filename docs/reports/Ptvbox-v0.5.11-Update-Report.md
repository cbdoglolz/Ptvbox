# Ptvbox 0.5.11 无 TMDB 剧集与播放器修正

版本：`0.5.11` / versionCode 18  
日期：2026年11月25日

## 本版修正

### 首页与动画

- [x] Home按钮在纵向列表内部增加10dp顶部留白，焦点框完整显示在Ptvbox Logo和版本号下方。
- [x] 动画年份恢复为独立大字，位于“季度新番/当季热播”下方、圆形加减号上方。

### 无 TMDB Key 的豆瓣季集

- [x] `Work` 新增 `episodeCount`，兼容旧缓存 JSON。
- [x] 豆瓣详情读取 `episodes_count`；缺失时回退解析 `episodes_info`、简介中的集数。
- [x] 没有 TMDB Key 时，使用豆瓣总集数生成可选的第1至第N集。
- [x] 单季豆瓣目录改为紧凑季标签，不再占用大块季海报空间。
- [x] 真实豆瓣《两京十五日》接口返回26集，详情页已实际渲染26个可选集数。
- [x] 无分集剧照时使用16:9集数占位；有剧照时使用返回图片，不主动裁切。

### 单集卡片与简介

- [x] 单集封面严格使用16:9容器。
- [x] 卡片宽度280dp、高度286dp，边框随整卡缩放并位于最外边缘。
- [x] 长集名按长度切换14/12.5/11/9.5sp字号，最多三行完整显示。
- [x] 简介移出卡片，放在当前焦点集状态下方的独立框体。
- [x] 简介默认最多两行；超长时显示省略号和“点击展开”，再次点击折叠。
- [x] 简介为空时不生成框体。
- [x] 集数评分缺失时明确显示“本集评分未公开”。

### 推荐和演职人员

- [x] 相似推荐改为每行六个，并按6个一组增加后续行。
- [x] 焦点位于已加载最后一行的最后一卡时，再按向下会加载下一页。
- [x] 演员和出品方作品页改为每行六部，并保留`pagedDown051`瀑布流触发。

### 私有站点提示

- [x] Toast拦截从插件请求线程提前到独立`:spider`进程初始化。
- [x] 更新Toast服务反射查找方式，并增加`Unsafe`静态字段写入回退。
- [x] 插桩验证`:spider`进程`noticeHook=true`。
- [x] 应用内广告过滤、扫码观看、免费资源、跳过广告和网盘二维码文本继续过滤。

### 播放器

- [x] 选集面板现在显示集名、评分、评分人数、时长或已保存总时长、上次进度。
- [x] 单击左右方向为5秒。
- [x] 长按后的1秒步进重复间隔由250ms改为50ms，执行速度提高到原来的5倍。
- [x] 分钟后和5分钟后的递进间隔也同步缩短。
- [x] 弹幕设置不再因修改参数而重绘整个播放器纹理。
- [x] 区域和飞行距离标签保持固定，不再在选中时重建不同语义文本。
- [x] 每个数值选项保留自己的FocusRequester，并在状态更新后延迟恢复焦点。

## 验证

- 114项JVM测试通过，0失败，0跳过。
- 豆瓣真实接口：`35235320 / 两京十五日 / episodes_count=26`。
- 隔离模拟器实际显示26集可点选卡片与16:9占位。
- Toast插桩：`{"noticeHook":true,"suppressed":0}`。
- 弹幕本地状态更新：区域25、字号24。
- 未连接正在使用的机顶盒。
