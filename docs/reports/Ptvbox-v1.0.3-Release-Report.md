## 验证证据与边界

候选证据来自本机`artifacts/qa-1.0.3/`及三个候选报告：c1验证媒体/动画/弹幕/下载/触摸，c2按所有者反馈恢复系统画中画和线路分组排序，c3为最终搜索/推荐状态。c1已删除的小窗测试仅为历史证据。

c3：174项JVM，0失败/错误/跳过；640×360dp和1280×720dp触摸/鼠标/D-pad搜索回归，包含来源、历史、空输入、中文/首字母/空格/删除、快速编辑、联想进入与返回、两个弹窗。HTTPS手机搜索表单真实Enter提交到电视并返回目录结果；该证据不代替实体手机扫码。实时豆瓣双向系列检索、AniList8条明确关系和实际详情页跳转通过。模拟器无SpeechRecognizer服务，语音只验生产弹窗和关闭。

本轮正式版需要另行核对：双包构建、174项测试、原证书/包名/44递增编号/ABI/资产和私密材料审计；GitHub Actions标签源码一致、公开Latest、仅两个APK、实际下载哈希/签名/版本、无凭据公开更新入口、隔离模拟器覆盖候选安装。状态与最终SHA-256在下方追加，不能把准备状态写成已上线。

## 交付及发布规则

- 交付是支持触摸/鼠标和D-pad的横屏ATV通用与ARM APK；ARM包可传到手机手动测试，不是已完成原生手机App。
- Release标题/正文仅`Ptvbox 1.0.3`，附件仅`Ptvbox-1.0.3.apk`、`Ptvbox-1.0.3-ARM.apk`。报告、日志、截图、源码和签名材料不作为附件。
- 先保留候选目录；公开发布并验证两包后再清除`artifacts/candidate-v1.0.3/`。不通过卸载/清数据处理覆盖升级。
- `WECHAT_WEBHOOK_URL` Secret当前缺失，现有工作流仅在配置后发送真实版本通知；本轮不能宣称企业微信送达。
- PCBOX只读，实体设备未操作。所有私密地址和签名材料留在忽略目录。
