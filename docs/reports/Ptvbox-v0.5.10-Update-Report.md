# Ptvbox 0.5.10 详情与剧集交互修正

> 后续修正：0.5.11补齐无TMDB豆瓣选集、紧凑16:9占位、独立简介、推荐瀑布流、插件Toast、播放器选集信息与新快进节奏。请优先使用0.5.11。

版本：`0.5.10` / versionCode 17  
日期：2026年11月25日  
构建类型：横屏 ATV APK，兼容遥控器、鼠标和触摸

## 本版修正

- [x] 整部作品收藏恢复为与播放、观看状态、搜索高清源相同的按钮尺寸、底色和间距。
- [x] 收藏只把左侧空心星改为黄色实心星，并稍微放大；不再改变整颗按钮的外框风格。
- [x] 单集收藏应用同一规则。
- [x] 整部作品选择已看、在看或想看后，按钮文字和横幅观看状态同步更新。
- [x] “校正季集关联”移动到“刷新全部资料”右侧，季与单集标题栏不再重复放按钮。
- [x] 单集封面改为严格16:9容器，按完整画面适配，不主动裁切。
- [x] 单集卡片加宽并放大封面，去掉卡片内部简介。
- [x] 集名根据长度自动减小字号和行高，最多三行完整显示。
- [x] 光标移动到某一集时，在该集横向轨道下方显示独立简介框；简介为空时不显示。
- [x] 豆瓣/TMDB评分横条移动到片名艺术字上方。
- [x] 删除出品与播出下方重复的剧情简介模块。
- [x] 相似推荐改为一行固定六部。
- [x] Home按钮下移并禁用自身向上放大，焦点框不会顶到Ptvbox Logo/版本区域。
