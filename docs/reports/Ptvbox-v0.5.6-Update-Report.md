## 本版完成

- [x] 删除非播放页右上角“搜索影视作品”和主题切换；搜索保留在左侧导航，深浅主题只放在设置的外观页。
- [x] “显示未上映”从来源切换行下移，放到“热门剧集”左侧。
- [x] 详情页删除固定返回按钮，返回统一使用系统/遥控器 BACK。
- [x] “刷新全部资料”从详情页顶栏移到“搜索高清源”右侧。
- [x] 详情页年份、电影/电视剧、国家和地区、类型标签改为可点击分类入口；点击后按当前作品类型进入豆瓣标签筛选。
- [x] 单集剧照右下角恢复观看状态徽标：已看绿勾、想看粉心、在看紫色眼睛；所有图标使用渐变和外圈。
- [x] 单集底部观看状态按钮使用相同绿/紫/粉渐变，只显示文字；选择弹窗缩成两行，已看、在看、想看、未标记、关闭可在小屏一页内完成。
- [x] 弹幕设置增加独立显示区域：1/4、1/2、3/4、全屏。
- [x] 弹幕设置增加横向飞行距离：1/3、1/2、2/3、3/4、全屏，默认全屏。
- [x] 修复弹幕默认提前在屏幕右侧消失的计算问题；全屏模式从右边界进入并完整移动到文字完全离开左边界。
- [x] 直播与体育标题、继续频道、来源和分类改为同一个滚动列表内容，手机端滑动频道列表时表头会一起滚走；全局品牌顶栏在该页面隐藏。
- [x] 直播频道读取期间显示明确文字和六张占位卡片，不再出现空白等待页。
- [x] 动画页改为左侧季度导航、右侧海报墙；左侧包含年份、冬春夏秋、每周更新数量、全部/周一至周日和动画源入口。
- [x] 从 PCBOX 当前资源迁入 18 个 Kazumi 动画规则，并注册到现有站点、作品身份、详情、选集和播放链路。
- [x] 新建 Android 可用的轻量 XPath 解析器，替代会在 Android 系统 DOM 上抛出 `DocumentImpl.getUserDataMap` 异常的 Jsoup `selectXpath`。
- [x] 动画规则直接媒体地址绕过代理播放页；giriGiriLove 的 MP4 集数现在直接进入播放器。
