# Ptvbox 0.7.0 设置重构、详情压缩与分类选源方案

版本：`0.7.0` / versionCode 20  
日期：2026年11月26日  
构建类型：横屏 ATV APK，兼容遥控器、鼠标和触摸

## 本版完成

### 设置焦点与手机扫码

- [x] 修复设置页从左侧栏目进入右侧后无法返回右侧的问题。切栏目后明确请求右侧内容焦点，弹窗关闭后恢复到原配置按钮。
- [x] 左侧名称改为“手机扫码局域网”，删除重复的内部标题和卡片标题。
- [x] “点击扫码”生成二维码；左侧放“关闭二维码”和局域网地址，右侧显示二维码。
- [x] 二维码出现后可用方向键从左侧操作按钮移动到右侧二维码。
- [x] “申请TMDB Key”移到这里。
- [x] 注释缩短为同一WiFi、10分钟有效和证书指纹提示。

### 界面与影视资料

- [x] 删除独立的“外观与海报操作”栏，主题和海报点击规则并入“界面”。
- [x] 删除没有实际差异的电视配置档位；未实现强制的16:9/4:3比例没有伪装成可用。
- [x] TMDB Key 改为外部只读显示、按钮打开弹窗；输入、复制、测试、历史记录、保存、删除均在弹窗内。
- [x] 历史Key最多保存8条，可选用、删除；当前Key可删除。所有保存值在外部明文显示，空值显示“配置”。
- [x] 删除“海报主评分”。

### 点播、直播与播放

- [x] 点播订阅和直播订阅改为相同按钮式弹窗；保存后外部显示完整地址。
- [x] 删除“当前站点 / 默认解析器”和设置内的“ATV系统首页”。
- [x] 删除默认倍速选项，播放器固定从1.0×开始。
- [x] 增加“测试当前并发”。实测4路设置运行20个任务，峰值并发4、耗时约0.75秒，证明设置进入同一信号量。

### 字幕与弹幕

- [x] 所有字幕服务输入改为按钮弹窗；复制、测试、保存、删除均在弹窗内。
- [x] “OpenSubtitles V3 公共聚合”置顶，无需API Key或账号；按IMDb/TMDB身份匹配。
- [x] 所有弹幕服务输入改为按钮弹窗。
- [x] 公共兼容弹幕默认置顶；B站公开弹幕作为无需配置的自动回退。
- [x] 公共字幕实测接口可达：`reachable=true`、`requiresApiKey=false`；测试片《肖申克的救赎》当前返回中文结果0条。中文覆盖和限流由公共提供方决定，不能宣称全片库可用。

### 隐私与手机配置

- [x] 删除“隐藏密码与密钥”开关和确认隐藏流程。
- [x] 已保存密码与密钥始终明文显示；磁盘保存仍使用Android Keystore加密。
- [x] 手机配置页同步使用卡片、点击配置、弹窗保存/删除、外部显示保存内容。
- [x] 手机端同样显示免费字幕和弹幕置顶项。
- [x] “站点与云端源维护”从TV设置左栏删除，仅保留在手机扫码配置页。

### 单集详情

- [x] 卡片压缩为248x244dp。
- [x] 右下角标记与左侧“继续播放/未播放”放在同一水平行。
- [x] 标记不遮挡标题、评分或进度。
- [x] 观看标记弹窗删除“关闭”按钮，点外部、选择状态或按返回关闭。
- [x] 简介仍可自动滚入可见区域并由方向键聚焦。

### TMDB与动画加载

- [x] 资料加载先解析TMDB身份并优先更新中文海报、标题艺术字和中文标题，再补齐豆瓣与详细评分。
- [x] 单集资料没有缓存时延后800ms，让中文标题/海报先显示；有缓存立即使用。
- [x] 展示资料缓存由24小时调整为12小时，短期内不重复请求。
- [x] 动画季度缓存保持12小时；未匹配到中文名时明确显示“中文名补充中”或“中文名未匹配”，不再只显示日文标题让用户猜测。

## 分类选源方案

- [x] 已完成[分类片源优先级方案](../plans/CONTENT-TYPE-SOURCE-PRIORITY.md)。
- [x] 建议分为中文真人剧、中文电影、日本/韩国真人、欧美影视、动画、纪录片/综艺、未识别类型。
- [x] 中文内容默认优先私人订阅和默认点播；动画优先动画资源；外语优先HDHUB/国际站。
- [ ] 本版没有直接启用分类规则。现有扫描仍是按站点顺序启动后共享并发信号量，不是严格的分类分波搜索。
- [ ] 下一版需要新增内容分类器、规则JSON、分波调度和设置界面，不能把当前排序冒充已完成。
