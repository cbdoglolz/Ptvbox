# Ptvbox v1.0.2 正式版更新报告

- **正式版本**：`1.0.2`（`versionCode = 40`，标签 `v1.0.2`）
- **发布日期**：`2026-11-27`
- **交付形态**：Android TV 横屏 APK（同步支持遥控器、鼠标与触摸操作，并非原生竖屏手机 App）

## 一、本版主要更新内容

### 1. 视觉与导航体验全面升级
- **品牌与桌面图标重塑**：基于方案 A 在 Figma 精修提亮毛玻璃质感应用图标 `brand.png` 与 Android TV 16:9 桌面横幅 `tv_banner.png`，并重绘左侧导航栏全部 8 枚矢量图标（动画图标升级为经典米老鼠剪影）。
- **首页影院横幅与来源栏统一设计**：豆瓣 / Netflix / TMDB 统一深空玻璃胶囊底座；海报双评分外置至海报下方不遮挡画面；按钮精简为低调玻璃态「详情」与「下一部 ›」；覆写 `LocalBringIntoViewSpec` 彻底解决 Android TV 焦点弹跳与横幅顶部裁切；「继续观看」最左项左移直达搜索图标。
- **影片详情页与选集体验**：压暗背景并加毛玻璃资料卡片；有观看进度的剧集自动滚动并聚焦至上次观看集卡；番剧时间表两行紧凑布局；搜索框高对比聚焦态。

### 2. 搜源、跨季匹配与站点管理
- **TMDB 合季 vs 国内分季系统性匹配（`SplitSeason102`）**：结合 TMDB 播映日期断档（≥60 天自动切分第 1/2/3 季）与站点多季累计集数双策略，自动将如《药屋少女的呢喃》第 1 季第 29 集匹配至国内第二季第 05 集（`S2E05`），并保留完整 60 集目录与进度。
- **站点自动计分与 3 列网格**：按真实探源结果自动计分（`+1` / `+0.5` / `-1`）并默认按分由高到低优先检索；新增 `好站 / 差站` 筛选、`关闭全部负分站`、`清零计分` 与「找到可用源后自动停扫条数」（`1/2/3/5/8条/不限制`）。
- **Netflix 国际高清路由 & 简介译名提取**：Netflix 作品（含日韩剧/电影）优先搜索国际高清（HDHUB）；自动提取简介 `《译名》` 中文优先搜索并支持 ±1 年跨年容差；非动画作品跳过 25 个纯动画站；内置动画规则扩充至 25 个；同片切集优先复用当前工作站点。

### 3. 播放、字幕、弹幕与性能稳定性
- **稳定性与 Shield TV 3GB 降载**：根治隐藏 WebView OOM 导致主进程被杀；将搜源全流程移至后台协程并节流刷新 UI，消除扫描卡顿；修复 `:spider` 断连 30 分钟冷却死锁；根治点播反复拉取 M3U8 导致的广告/UC 扫码弹窗风暴（`SpiderProxy` 30 分钟缓存 + `#EXT-X-ENDLIST` + `CloudPolicy054` 站点/线路拦截 + 静默 `Notify` + 空闲 `:spider` 自动释放）。
- **播放器控制与线路标识**：按方向键下默认落「播放线路」；线路左上角统一电影级徽章（`4K/1080P` → `DV` → `HDR10+/HDR` → `ATMOS/DD+/DTS/TrueHD` → `7.1/5.1` → 多语/语种）；「▶ 继续搜索」常驻候选数右侧与播放线路顶部。
- **音轨、字幕与弹幕增强**：
  - 新增音轨/字幕自动加载语言优先级（默认 `中文 → 英语 → 片源默认`），并在音轨面板右上角提供「音频优先级设置」一键跳转；
  - 播放界面上方区分内嵌字幕（`字幕 ON / OFF`）与外挂字幕（`外挂字幕 ON / OFF`），切回内嵌自动恢复；
  - 弹幕数学级静态预分轨消除打架与跳轨；上方弹幕计数有数据时显示量词（如 `弹幕 ON 326条`），无数据时显示 `弹幕 ON 0`；重构美化弹幕设置面板；
  - 修复续播时「选集」仅显示当前 1 集的问题，完整展示整季分集并自动定位当前集。

### 4. 设置与局域网扫码配置
- 设置页左侧上下切换仅预览右侧不抢夺焦点；打开二维码后移回「手机扫码局域网」不再自动跳至「关闭二维码」。
- 移除 TV 端「申请TMDB Key」按钮并仅保留在手机扫码配置网页；电视端补充自签 HTTPS 局域网「不安全」提示说明；Android 11/12 私人源提供关闭系统通知引导页。

## 二、验证证据与边界说明

- **自动化单测**：157 项 JVM 单元测试全部通过（含 `Version102Test` 跨季匹配、续播分集、电影徽章、语言优先级、外挂字幕/弹幕状态文案、站点计分、网盘拦截等）。
- **模拟器实机证据（BlueStacks 静音验收并清理）**：已完成首页无裁切与焦点稳定性、设置页二维码不跳右、续播全集选集、音轨跳转音频优先级设置、弹幕条数量词以及《药屋少女的呢喃》第 1 季第 29 集自动匹配 `S2E05` 1080P 实机起播截图验证；验收后均已强停应用并恢复原音量。
- **物理设备状态**：已将签名 ARM 包安装至所有者授权 Shield TV（`192.168.2.131:5555`）；受保护设备（`192.168.2.114:5555`）全程未触碰。
- **PC 对等与后续范围**：原生竖屏手机 App、PCBOX 完整双向迁移、全站/全直播首帧覆盖仍不在本版完成声明内。
