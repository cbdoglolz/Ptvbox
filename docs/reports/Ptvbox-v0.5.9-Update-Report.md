# Ptvbox 0.5.9 修正版交付报告

> 后续修正：0.5.10继续修复了收藏按钮外壳、观看状态同步、16:9单集卡片、独立简介框、评分顺序、六列推荐和Home焦点间距。请优先使用0.5.10。

版本：`0.5.9` / versionCode 16  
日期：2026年11月25日  
构建类型：横屏 ATV APK，兼容遥控器、鼠标和触摸

## 修正的问题

- [x] 找到 0.5.8 详情页未生效的真实原因：`MainActivity` 路由到 `CinemaDetail040`，0.5.8 却修改了未被路由的 `CinemaDetail`。
- [x] 实际详情页改为单个横幅：左侧海报，右侧片名艺术字/标题、简介、分类、评分、上映日期和观看状态。
- [x] 播放、收藏、观看状态、搜索高清源和刷新全部资料移到横幅外下方。
- [x] TV 剧集区移动到普通线路目录之前。
- [x] 整部作品收藏改为与单集一致的金色星，不再使用选中背景填充。
- [x] 单集卡片的放大和渐变细框改到整卡外层；卡片放大时边框同步缩放并保持在最外侧。
- [x] 全局遥控焦点由实心紫色改为半透明深蓝灰底、青色到紫色渐变描边和柔和光晕。
- [x] 所有选中项的公共 `selection051` 改为细描边，不再铺满实色渐变大背景。
- [x] 播放器、侧栏、操作按钮、搜索页和弹窗统一使用同一焦点色调。
- [x] 动画年份减号、加号改为圆圈内居中显示，保留外侧 `-5` 与 `+5`。
- [x] 豆瓣与 TMDB 评分容器改为等高区域，标签、数字和人数使用相同中心线。
