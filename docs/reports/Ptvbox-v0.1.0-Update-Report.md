# Ptvbox v0.1.0 本地更新报告

日期：2026-11-15。交付性质：原生Android TV首轮测试版，尚未完成PCBOX全部功能迁移。

## 本次已实现

- 建立Kotlin、Compose for TV、Media3原生工程，独立包名 `com.cbdog.ptvbox`。测试包使用 `.debug` 后缀，不覆盖现有电视应用。
- 豆瓣海报首页、电影/剧集/动画栏目、Netflix标签资料、可选TMDB个人密钥、详情先于播放。
- 方向键/确认/返回、明显焦点、海报标准竖版比例、切换栏目时保留已加载目录与滚动状态；左侧正在播放入口独立显示片名/集数/时间与停止按钮。
- 系统语音搜索入口及不可用回退；对已缓存目录支持拼音首字母搜索，不把首字母直接当作中文查询发送到所有资源站。
- MacCMS搜索、详情、播放组/集数解析、20路并发、暂停后续扫描、检测计数、后台重新检测保留当前播放、失败换线、25秒无首帧保护。
- SQLite收藏/历史/进度、优先恢复上次站点与线路、播放音量保持；音轨、内嵌字幕及倍速入口已接Media3。
- 个人密钥与私人订阅使用Android Keystore加密保存；不复制PC凭据、Cookie或观看数据库。

## ATV系统首页

已接入系统Watch Next（接下来播放）。播放进度定期写入，离开应用时保存并暂停；系统卡片通过深链回到对应作品续播。看完后移除本应用对应卡片；用户从系统移除的卡片不会无条件反复添加，重新主动播放才恢复加入。

推荐频道定义如下，稳定标识固定：

| 标识 | 名称 | 条件/数据 |
|---|---|---|
| `douban-tv` | 豆瓣 · 热门剧集 | 无需TMDB Key |
| `douban-movie` | 豆瓣 · 热门电影 | 无需TMDB Key |
| `netflix-tv` | Netflix · 热门剧集 | 豆瓣Netflix标签资料；不是Netflix官方榜单 |
| `netflix-movie` | Netflix · 热门电影 | 同上 |
| `tmdb-tv` | TMDB · 热门剧集 | 配置有效个人Key后创建 |
| `tmdb-movie` | TMDB · 热门电影 | 同上 |
| `anime-new` | 动漫 · 最近更新 | 当前按豆瓣最新动画目录排序，不代表逐集更新时间 |
| `anime-hot` | 动漫 · 热门 | 豆瓣动画目录 |

- 无Key时提供6类，配置TMDB并验证成功后立即刷新另2类。
- 每类最多20部。每6小时请求刷新，设置中可以手动刷新；失败保留已有资料。
- 系统首页 → 自定义您的主屏幕/自定义频道 → Ptvbox，可分别开关。Ptvbox设置中也有系统添加授权入口。
- 海报采用本机只读缩略图缓存，供系统桌面跨应用读取，避免桌面缺少资源站请求头而显示灰图。仅缓存豆瓣/TMDB公共海报，拒绝路径穿越和写入，不开放数据库或凭据目录。
- 缩略图缓存预设100MiB清理阈值，保留系统频道及Watch Next仍在引用的图片。

## 修复原因与过程

1. TV按钮默认圆角形状把海报裁成椭圆：改为固定小圆角、2:3画布。
2. 应用内海报缺少豆瓣图片请求头，且详情封面对象可能指向网页：补齐图片请求头，并优先使用图片字段。
3. 推荐条目年份在部分接口的副标题中：补充读取副标题年份；TOP250按电影类型解析，避免进入剧集详情接口。
4. 系统频道添加按钮最初从Application启动，实际没有出现授权界面：改为Activity Result调用后，盒子真实显示“添加频道”弹窗，批准后频道可见。
5. 系统桌面无法沿用应用内图片加载器：改成本机只读海报接口后，真实桌面已显示海报。
6. 返回浏览期间要保留播放器；真正切到系统首页则应保存并暂停，避免退出后继续消耗带宽：区分应用内导航与Activity后台生命周期。
7. 本机签名密码文件换行导致二次构建读取失败：读取时清理末尾换行，保留原签名密钥，没有重新生成更新身份。

## 实际验证

以下是不同证据，不能把构建或接口响应等同于实际播放：

- JVM单元测试：11个测试场景通过，不是11条播放用例。覆盖年份排错、季数排错、别名、集数形式、拼音、播放组解析、进度序列化、6/8类频道条件和稳定标识。
- 物理设备：已授权Homatics Box R 4K Plus，Android 14、32位 `armeabi-v7a` 系统。APK安装和启动成功。
- 豆瓣首页：真实加载20条并显示海报；修复椭圆裁剪后检查了实机画面。
- 剧集：《西游记》第一集，魔都线路完成播放链路，记录432p视频尺寸及进度。
- 电影：《肖申克的救赎》，魔都线路完成1080P首帧、跳转、保存进度、返回详情、内部浏览保留播放、同站点1080P续播。
- 为排除设备视频层不进入普通截图的情况，使用PixelCopy取得了真实视频图像，结果成功；不是只有转圈或媒体配置。
- 系统频道：无Key的6类各写入20部；系统“自定义频道 → Ptvbox”真实列出全部6类。豆瓣热门剧集已完成系统添加授权，首页能显示海报，遥控器点击卡片进入正确详情且没有自动播放。
- Watch Next：实机首页真实显示测试影片海报与进度条；用遥控器点击后进入Ptvbox并续播，数据库再次记录 `builtin_mdzy / modum3u8 / 1080p`，位置从约73秒继续增长至约106秒。完成标记移除测试卡片通过。
- 收藏新增/取消、进度保存通过；本地测试数据库与真实用户PC数据隔离。
- 清理了本轮创建的6个QA频道及单独的QA Watch Next测试卡片；正式包频道和其他应用频道保留。没有清空应用资料、收藏或用户配置。
- 播放前电脑默认输出已静音并回读；盒子测试播放器音量设为0，未修改盒子系统音量。播放测试后电脑恢复原状态并回读为未静音。
- 签名APK和包内容检查见本地验证文件；未上传任何APK、报告或日志。
- 最终安装包与本地交付包SHA-256一致；签名证书保持一致，Release不可调试，包含32位ABI，且不包含QA Instrumentation。
- 海报接口跨应用读取成功；写入和路径越界请求按预期被拒绝，原图片校验值未改变。默认32站配置与PC公开默认配置逐字节一致。

## 来源与栏目变更

- 来源：沿用PCBOX公开默认配置中的32个MacCMS站点；站点名称、稳定key未新增、未修改、未删除。Android只对受支持的接口执行搜索，不把Jar/JS等未支持协议伪装成可用。
- 新增栏目：上表8个ATV系统频道；其余应用已有系统栏目不修改。
- 实际播放成功的是本次具体测试线路，不代表32站全部可播。探测为候选的线路也不等于全部通过出画面验收。

## 尚未实现/未验证

- 还不是PCBOX完整ATV版。Jar/JS/Python兼容、国际高清和动画规则引擎、直播体育、小雅/GBOX/AList/WebDAV、扫码授权、在线字幕和字幕校时、自动弹幕、广告标记优先级、HDR/Dolby映射、源更新签名激活/回退、APK在线升级仍需逐项移植。
- 测试魔都流存在内嵌文字广告；当前Android实现不能去掉视频内已编码的广告文字，不宣称已有PC广告优先级功能。
- 电视端尚未填真实TMDB Key，未实测其2类频道；真人语音输入、多音轨/多内嵌字幕样本、全部遥控器页面、长时间播放、6小时和重启定时刷新尚未完整验收。
- 本轮直接在已授权实机验证；没有把其他项目或旧模拟器测试算成本项目通过项。
- GitHub构建workflow已写在本地，未推送或云端执行；PC新版本触发与完整功能兼容映射尚未接通。不会仅改版本号就宣称自动移植完PC功能。企业微信Secret仍按用户决定稍后配置，本轮没有发送通知。
