## 本轮问题定位

1. **面板后返回漏键**：日志显示原生面板关闭后焦点恢复期间，系统默认Back跟踪漏掉后续一次按键；并非模型的三层back reducer本身错误。播放器根按键层统一消费Back down/up并在up执行，面板原层级保持。修复后实际注入三次短返回，逐层到详情并保留会话。
2. **系统HOME验收方法**：BlueStacks内Instrumentation直接发HOME键没有实际离开前台（仍有窗口焦点），该失败记录保留，不能当成功。改用Android系统GLOBAL_ACTION_HOME，实际前台退出后current=false、playing=false、mediaItemCount=0、windowFocus=false；进度已落库，返回再起播成功。
3. **自动扫不相关插件**：订阅中17站的searchable=0此前未被消费，自动搜索仍会触发网盘/直播等插件，带来额外请求和第三方提示。本次修正自动搜索资格并加回归；不将其等同所有第三方插件都能完全取消在途线程。
4. **Logo转换**：SVG的紧凑arc参数及长宽比被Android矢量原生解析误读；本轮截图复查发现后规范化路径并重新打包。PC原素材只读，没有修改Windows项目。
