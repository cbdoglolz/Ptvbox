# Ptvbox 0.8.0 私有源提示、播放手势与设置收口

版本：`0.8.0` / versionCode 21  
日期：2026年11月26日  
构建类型：横屏 ATV APK，兼容遥控器、鼠标和触摸

## 本版完成

### 私人订阅广告/扫码提示

- [x] 找到覆盖缺口：此前只在独立`:spider`进程安装系统Toast代理，主进程如果加载同一批TVBox基础类仍可创建系统Toast。
- [x] 主应用进程和`:spider`进程都在启动时安装`INotificationManager`代理。
- [x] 主进程真实Toast验证：`suppressedDelta=1`、`toastVisible=false`。
- [x] 插件进程真实Toast验证：`suppressed=1`、`toastVisible=false`。
- [x] 应用自己的Compose提示不受影响。
- [x] 额外过滤“已过滤视频中广告”“网盘源需使用扫码登录”“饭：”等私人源噪声，即使它们被转成应用内文字通知也不显示。
- [ ] 没有连接真实电视并重放用户的完整私人订阅；如果某插件绕过Android Toast、自行绘制原生悬浮窗，本版不能保证覆盖该非标准实现。

### 视频详情背景

- [x] 背景图从TMDB `w780`提高到`w1280`。
- [x] 背景模糊从14dp降低到7dp。
- [x] 背景不透明度从0.66提高到0.78。
- [x] 仍使用铺满裁切和渐变蒙层，但不再因过强模糊显得像低分辨率拉伸图。

### 手机播放手势

- [x] 单指单击画面显示控制栏。
- [x] 双击屏幕中间切换播放/暂停。
- [x] 双击左侧后退5秒。
- [x] 双击右侧前进5秒。
- [x] 长按屏幕临时2倍速，松开恢复。
- [x] 水平左右拖动按屏宽比例预览时间位置，松手后跳转。
- [x] 直播页不执行拖动跳转，避免对直播流做无效seek。
- [x] 手势层位于视频上方、控制栏下方，保留遥控器和按钮操作。

隔离模拟器手势结果：

