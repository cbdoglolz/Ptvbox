# Ptvbox 1.0.0 私有源提示加固与真实播放验收

版本：`1.0.0` / versionCode 24  
日期：2026年11月26日  
构建类型：横屏 ATV APK，兼容遥控器、鼠标和触摸

## 根因与修复

用户看到的“此资源失效”“已过滤视频中广告”“网盘源需使用某网盘APP扫码登录”来自私人 TVBox 插件。上一轮只验证了插件扫描阶段和单条通用 Toast，没有完成“私人源真实出片后持续播放”的验收，因此不能作为问题已解决。

本版在主应用进程和独立`:spider`插件进程都在插件代码执行前安装通知服务代理。代理不再只匹配固定方法名，而是覆盖所有名称含 Toast 的`enqueue*`和`cancel*`系统调用，以兼容厂商修改过的框架方法。应用自己的 Compose 提示不经过该代理。

同时保留应用内提示过滤，覆盖：

- “此资源失效”
- “饭：已过滤视频中广告”
- “网盘源需使用……扫码登录”
- “百度网盘APP扫码”

## 对照原始开发要求的验收清单

- [x] 私人订阅视频播放时过滤插件广告、失效和扫码 Toast。
- [x] 私人订阅来源不因提示过滤破坏正常播放器状态。
- [x] 手机/电视 APK 同时支持触摸、鼠标和方向键操作。
- [x] 设置菜单、片源配置、字幕/弹幕、详情页、播放手势和分类选源功能保留在1.0.0。
- [x] 动画中文资料、多站ID推理、标题数字/别名归一和详情缓存保留在1.0.0。
- [x] 本轮提供可覆盖安装的通用和ARM签名APK、哈希、测试证据和限制说明。
- [ ] 真实电视主屏、真实遥控器手感和当前用户私人订阅全量播放仍需用户设备复测。
- [ ] 第三方插件非标准自绘悬浮窗需要取得对应实现后才能逐项兼容。
- [ ] 全部默认站、国际站、直播、动画规则和长时播放没有被宣称为全量通过。
- [ ] PCBOX功能矩阵仍不是完整对等。

## 建议下一步

1. 用户在当前电视或手机上覆盖安装1.0.0 ARM包，优先测试此前反复弹提示的私人订阅作品。
2. 如果仍有提示，记录出现时是否在扫描、选源、播放首帧或播放中，并提供一张含提示的屏幕照片；据此可区分Toast、应用内文字和插件自绘窗口。
3. 继续保留真实设备证据与模拟器证据分开记录，不把本次40秒私人源播放验收称为全量私人订阅通过。
