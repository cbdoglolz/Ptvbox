# Ptvbox 0.9.0 弹幕预览、分类选源与多源身份

版本：`0.9.0` / versionCode 22  
日期：2026年11月26日  
构建类型：横屏 ATV APK，兼容遥控器、鼠标和触摸

## 本版完成

### 弹幕实时预览

- [x] 弹幕设置右侧增加虚拟屏幕，里面有持续漂浮的示例弹幕。
- [x] 左侧字号、不透明度、密度、横穿秒数、横向飞行距离和颜色变化会即时反映到右侧预览。
- [x] 预览和播放器使用同一组`danmaku_*`配置，不是独立演示参数。
- [x] 预览区域裁切在自己的边框内，不会溢出到设置页。

### 分类选源

- [x] 站点页增加紧凑的“分类选源”入口。
- [x] 支持七类：中文剧集、中文电影、日韩影视、欧美影视、动画、纪录片/综艺、未识别。
- [x] 每类可独立调整“私人订阅、默认点播、国际高清、动画”等分组顺序。
- [x] 支持上移、下移和恢复本类默认。
- [x] 选择动画时默认“动画”分组第一；欧美默认“国际高清”第一；中文默认“私人订阅/默认点播”优先。
- [x] 实际搜索从单纯排序改成按分组分波：上一组没有候选才进入下一组。
- [x] 原播放站点恢复仍优先；用户关闭的站点不会因规则重新启用。
- [ ] 本版只能调整分类内的分组顺序，尚未提供同一分组内逐个站点的拖拽细排。

### 动画日文来源

- [x] 确认动画季度主目录来自AniList，Bangumi只负责后续中文名和海报补充。
- [x] 原匹配要求过严，Bangumi中文匹配有歧义时保留日文，所以出现大量日文标题。
- [x] 现在优先从AniList多语言别名中选择不含假名的中文标题。
- [x] Bangumi匹配增加标准标题和去季数标题比较，明确同义词可降低歧义门槛。
- [x] Bangumi匹配后补充中文海报、评分、简介以及可用外部ID。
- [x] 仍未匹配中文名时明确显示“中文名补充中”或“中文名未匹配”，不再静默显示日文。

### 多网站身份与别名

- [x] `WorkFacts`新增豆瓣、TMDB、IMDb、Bangumi稳定ID字段，兼容旧缓存。
- [x] TMDB详情读取`external_ids`，得到IMDb ID。
- [x] 已有IMDb ID时通过TMDB `find`反向取得TMDB作品。
- [x] Bangumi infobox可提取IMDb、TMDB、豆瓣和Bangumi ID。
- [x] 豆瓣返回`imdb_id`时直接保存。
- [x] 缺失IMDb时可用Cinemeta按精确片名和年份补全，再反向查找TMDB。
- [x] 标题规范化统一全角/半角、大小写、标点、英文数字、罗马数字和中文季数，例如`Season Two`、`第2季`与`第二季`。
- [x] 详情片源信息会显示已确认的IMDb、TMDB、豆瓣和Bangumi ID。
- [x] 不能直接访问的跨站关系仍使用标题、别名、年份和类型交叉验证；歧义结果不强行合并。

### 资料加载缓存

- [x] 作品详情资料增加6小时文件缓存，重复打开优先使用已解析资料和外部ID。
- [x] “刷新全部资料”会使详情缓存失效并重新请求。
- [x] 展示海报、艺术字、评分仍使用12小时派生缓存。

## 未完成与验收边界

- [ ] 分类选源尚未提供同一分组内逐站拖拽顺序。
- [ ] 多源推理受各站公开接口限制，不能保证每个作品都同时拥有四个站点的ID。
- [ ] 有歧义或无年份的数据仍可能保留原名，不会为了中文标题强行错误合并。
- [ ] 未连接真实电视/手机，未全量重跑动画来源、豆瓣评分和所有片源首帧。
- [ ] PCBOX双向迁移、原生手机UI和完整PC对等仍未完成。
- [ ] 本版只生成本地签名测试包，未上传、未发布、未发送企业微信。
