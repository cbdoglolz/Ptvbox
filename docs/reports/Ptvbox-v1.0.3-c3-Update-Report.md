## 根因与方案依据

原搜索页依赖几何推断跨越输入区与联想网格，没有明确的左右入口；检索时本地结果还要等待在线接口结束。现在两区有显式入口和返回位置，本地与在线分阶段显示，过期查询不能继续出现在屏幕上。

原moreRelated只请求当前kind的TMDB推荐，或同kind豆瓣热门流，电影自然无法通过该路径找到TV版。新增跨类型搜索，并使用明确关系补齐标题不完全相同的动画作品。关系结构参照[AniList官方关系查询](https://github.com/AniList/docs/blob/master/docs/guide/graphql/queries/media.md)，跨类型检索参照[TMDB官方数据查找说明](https://developer.themoviedb.org/docs/finding-data)。相似推荐接口失败时，同系列查询仍能独立返回。
