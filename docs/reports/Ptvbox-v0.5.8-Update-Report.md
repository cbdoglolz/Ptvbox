## 本版完成

### 迁移与数据

- [x] 删除 PCBOX/PTVBOX 迁移界面的备份密码输入。
- [x] 导出改为可读 `PTVBOX-XFER` JSON 容器，包含订阅、凭据、收藏、观看状态、进度、手动关联与受限字幕缓存。
- [x] 导入保留两阶段流程：先预览摘要，再显式确认；预览不写入、不回显凭据，ticket 单次使用。
- [x] 手机配置网页同步删除密码框，导出、预览和确认请求均不携带密码。
- [x] 自动化和模拟器插桩验证无密码导出、无效文件不改数据、确认导入恢复数据和 ticket 单次使用。
- [ ] Windows PCBOX 的文件夹备份尚未转换成 PTVBOX-XFER 字段；当前完成的是 Ptvbox 自身换设备的无密码迁移基础。

### 导航、首页与片库

- [x] 左上 Logo 改为正方形、透明内部和渐变细边框，Logo 居中。
- [x] 首页海报获得焦点后轻微放大，并显示细渐变框。
- [x] 豆瓣/TMDB 评分使用固定高度行盒，文字基线垂直对齐。
- [x] 导航“搜索”改为“搜索筛选”。
- [x] 片库改为一行固定六部。

### 动画页

- [x] 删除动画页内部搜索、你可能也喜欢和 2017/2020/2023 快捷年份行。
- [x] 右上“刷新”改为“重置”，恢复当前年份、当前季度、当前星期和季度模式。
- [x] 年份两侧保留单步加减，并支持 `-5`、`+5`。
- [x] “近期热播”改为“当季热播”。
- [x] Bangumi 中文名匹配改为标准化精确/包含匹配、候选分数和第一/第二差距判断，减少错误覆盖；12 小时季度缓存继续保留。
- [ ] 没有 Bangumi 中文条目或唯一匹配时仍可能显示日文；这是数据缺口，不伪造中文标题。

### 详情页与单集

- [x] 详情顶部改为单个横幅：左侧海报，右侧艺术字片名、简介、可点击年份/类型/地区标签、双评分、上映日期和观看状态。
- [x] 播放、收藏、观看状态、搜索高清源和刷新资料移到横幅外下方。
- [x] 单集改为横向懒加载轨道，先显示骨架占位，再加载剧照、名称、评分、日期、简介和进度。
- [x] 单集卡片使用统一尺寸；名称、评分、日期和简介保留独立区域。
- [x] 单集获得焦点使用细渐变边框，不填充整卡。
- [x] 单集收藏使用金色星；观看状态使用绿/紫/粉文字和圆形徽标。
- [x] 观看状态弹窗删除“关闭”按钮，点外部或 BACK 关闭，选择项只显示渐变描边。
- [x] 相似推荐在宽屏一行六部。

### 搜索筛选

- [x] 详情分类标签直接进入搜索筛选页，不再回首页生成简陋筛选墙。
- [x] 结果可多选电影/剧集、已有类型标记和可解析的分辨率标记。
- [x] 支持默认紧凑、容量小到大、年份升降序和评分优先；缺失容量固定放末尾。
- [x] 搜索历史压缩为一列，文字缩小并省略过长内容；右侧改用更小海报，提高同屏数量。
- [ ] 资源站未返回类型、容量或分辨率时，界面不会猜测这些值。

### 播放器

- [x] 基础快进步长从 5 秒改为 1 秒；长按 5 秒后仍进入分钟级加速。
- [x] 暂停画面中央持续显示“已暂停”和当前时间/总时长。
- [x] 控制条左上保留完整片源名，右侧显示音轨/字幕/弹幕状态与进度。
- [x] 弹幕按钮改为圆形“弹”字，绿色 ON、红色 OFF，开启时显示已加载数量。
- [x] 弹幕已启用状态改为本地即时状态；参数点击不再主动抢焦点，焦点保持原选项。
- [x] 控制 UI 显示但焦点不在功能按钮时，确认键仍直接播放/暂停。
- [x] 选集状态显示集名、评分、日期、简介、上次进度和总数；卡片保持横向统一尺寸。
- [x] 扩展过滤“免费资源/请勿上当/跳过广告/扫描网盘/网盘二维码”等后台插件噪声。
- [ ] Girigiri 未缓冲区域无法快进仍需用真实媒体 Range/seekable 日志单独验收。
