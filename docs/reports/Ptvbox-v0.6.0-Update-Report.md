# Ptvbox 0.6.0 单集简介与插件提示修正

版本：`0.6.0` / versionCode 19  
日期：2026年11月26日  
构建类型：横屏 ATV APK，兼容遥控器、鼠标和触摸

## 本版完成

### 单集简介真正可见

- [x] 修复季集目录从“先占位、后补详情”更新时仍保留旧空简介对象的问题。现在按当前集号重新绑定最新集对象。
- [x] 当前选中集始终显示简介框；接口没有简介时明确显示“本集暂未提供简介”。
- [x] 切换到其他单集后，简介框同步切换到对应集。
- [x] 长简介默认两行，可点按展开和折叠。
- [x] 单集获得焦点后主动将简介框滚入可见区域，不再被下一块“作品资料与播放线路”遮住。
- [x] 简介框本身可获得遥控焦点，并向无障碍服务报告“当前焦点”。

### 单集卡片

- [x] 删除单集卡片内的收藏按钮，单集收藏入口不再与标记按钮混排。
- [x] 卡片由 280x286dp 压缩为 248x258dp。
- [x] 封面继续使用16:9完整显示。
- [x] 标题最多两行并自动缩小字号，完整标题保留在语义描述中。
- [x] 观看标记改为右下角34dp小圆钮，标记状态使用对应颜色。
- [x] 卡片底部预留30dp空间，圆钮不覆盖标题、评分、时长或续播进度。

### 观看标记弹窗

- [x] 已看、在看、想看、未标记四项全部保持在屏幕内。
- [x] 增加明确的“关闭”按钮，不再只能依赖点外部或返回键。
- [x] 选择状态或关闭后，焦点恢复到当前集右下角圆钮。
- [x] 触摸、鼠标和遥控焦点可操作同一按钮。

### 插件 Toast 与底部浮层

- [x] 在独立`:spider`进程加载插件前安装系统提示服务代理。
- [x] 拦截`enqueueToast`、`enqueueTextToast`、`enqueueToastEx`，并透传其他通知服务调用。
- [x] 保留普通反射和`Unsafe`静态字段回退，兼容隐藏API限制。
- [x] 调试钩子只在Debug构建启用，Release不能调用测试入口。
- [x] 隔离模拟器真实执行`Toast.show()`，结果为`noticeHook=true`、`suppressed=1`、`toastVisible=false`。

PCBOX桌面版并没有在文字层“过滤广告提示”。它的JAR桥把`android.widget.Toast`替换成宿主占位类，再交给`DialogHost`处理，所以桌面端不会生成Android系统Toast。Android需要使用本版的系统通知服务代理实现同类隔离。

## 未完成与验收边界

- [ ] 未连接或操作真实电视盒子；真实电视的遥控焦点、长按快进、面板动画和厂商Toast兼容仍需用户手动验收。
- [ ] 本版没有重新执行全量在线片源首帧和长时播放，不能据此宣称所有资源可用。
- [ ] ATV“接下来播放”和自定义首页频道保持既有实现；本版只验证模拟器安装与启动，没有重新操作真实TV主屏。
- [ ] PCBOX与Ptvbox完整双向字段迁移仍未完成。
- [ ] 原生手机UI仍未开发；本APK是支持触摸的横屏ATV测试版。
- [ ] 本版只生成本地签名测试包，未上传、未发布Release、未发送企业微信通知。

## 本版未做

- 没有新增资源站、直播源或字幕/弹幕服务。
- 没有修改播放器解码、HDR/Dolby或后台播放架构。
- 没有修改Windows PCBOX。

## 下一版范围

优先由用户把`0.6.0`安装到手机或电视盒子，手动验证：

1. 单集简介是否随选集变化并保持在可见区域。
2. 右下角圆钮在遥控器、触摸和鼠标下是否都能打开并关闭。
3. 私有站点广告、扫码和网盘提示是否不再以底部Toast遮挡内容。

拿到结果后，再决定是修复设备兼容，还是继续PCBOX/Ptvbox双向迁移与资源逐站验收。
