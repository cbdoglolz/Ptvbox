# Ptvbox 与 PCBOX 功能对照（当前1.0.0）

1.0.0已在主进程和插件进程拦截系统Toast，并用真实私人订阅候选播放40秒验证三类报告提示不可见。版本命名使用每段一位十进制，`0.9.9`之后直接进入`1.0.0`。该证据不覆盖第三方插件绕开Toast自绘的悬浮窗，也不代替真实电视设备验收；具体边界见[1.0.0报告](reports/Ptvbox-v1.0.0-Private-Source-Notice-Hardening.md)。

当前状态见文末0.9.0补充及报告。下面表格保留0.3.0历史基准，不是当前完成声明。
