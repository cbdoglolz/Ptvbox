# Ptvbox 与 PCBOX 功能对照（0.2.2）

当前为0.2.2本地ATV测试版，不是Windows程序自动转换，也不代表PCBOX全部功能已迁移。下表旧实机证据来自2026-11-15的0.1.0；本轮2026-11-20仅独立模拟器验证，不混为本轮实机结果。详见 releases/0.2.0/UPDATE.md。

| 功能 | ATV当前状态 | 验证边界 |
|---|---|---|
| 鼠标/触摸与遥控器共存 | 0.2.1修复 | TV与手机尺寸模拟器各10项输入检查；真实手机待测 |
| v2数据/独立收藏三态/十进制进度 | 已实现 | 本轮16项JVM、12项Android合成数据检查通过；真实用户库未连接 |
| 新首页/覆盖Drawer/播放前目录 | 已实现 | 本轮模拟器真实无Key目录和选集首帧；机顶盒性能未达成验收 |
| 豆瓣海报、电影/剧集、详情 | 已实现 | Homatics读取推荐与海报 |
| Netflix标签片库 | 已实现 | 资料来自豆瓣Netflix标签，不是Netflix官方榜单 |
| TMDB个人Key/季集 | 0.2.2验证入口、季集单集评分/本地标记 | BlueStacks真实Key与第二季13集/单集评分实测；账号云同步未实现 |
| 手机扫码配置 | 0.2.2临时HTTPS页面、配对、Key/订阅写入 | TLS及生产回调自动测试；真实手机WiFi未测 |
| 图标播放器/进度/全屏 | 0.2.2已接入 | 输入和多尺寸持续补测，非完整PC高级功能 |
| 遥控器方向键/确认/返回 | 已实现基础焦点和列表状态保留 | 正在逐页补充实机操作验收 |
| 语音搜索 | 已接系统识别入口及不可用回退 | 未做真人语音输入验收 |
| 拼音首字母 | 已实现已缓存目录检索 | 不会把首字母直接当作中文发送给各资源站；不是完整在线片库索引 |
| 默认32个MacCMS来源 | 已接入，名称和稳定key沿用PC | 电影、剧集魔都线路实测；不代表32站全部可用 |
| 20路检测、暂停、后台刷新保留当前播放 | 已实现 | 暂停阻止新请求进入，在途请求允许完成 |
| 收藏/本地历史/续播/音量保持 | 已实现 | 实机验证收藏、进度、相同站点与1080P续播 |
| 音轨、内嵌字幕选择与倍速 | 已接Media3 | 尚未用多音轨/多字幕样本逐项验收 |
| ATV接下来播放 | 已实现 | 实机首页显示海报/进度条，点击续播保持魔都1080P与保存进度，完成移除通过 |
| ATV推荐频道 | 8类定义；无Key时6类 | 实机6类各20部、自定义频道开关、系统添加授权与海报显示，推荐卡片回详情通过；TMDB两类待Key |
| 频道自动刷新 | 已实现6小时JobScheduler任务和手动入口 | 实机首次执行通过；长时间定时/重启待验证 |
| Jar/JS/Python兼容 | Jar宿主部分完成；JS/Python未实现 | 49个CSP进入适配路径，一个私人站点1080P首帧；不是49站全可用 |
| 国际高清/动画规则独立更新 | 未完成 | 不能复用Windows Node.exe；需Android适配器 |
| 直播/体育 | 未完成 | 不会将直播地址丢入点播搜索冒充播放 |
| 小雅/GBOX/AList/WebDAV及扫码授权 | 未完成 | 不复制PC个人订阅、Cookie和密钥 |
| 在线字幕/字幕校时/字幕缓存 | 未完成 | PC现有功能未改动 |
| 自动弹幕 | 未完成 | 不借用他人开发者凭据 |
| HDR/Dolby手动映射 | 未完成 | 当前使用Android平台解码；不宣称完整HDR/Dolby输出验收 |
| 源更新预览、签名激活、回退 | 未完成 | PC维护项目已有签名协议，Android引擎仍待接入 |
| GitHub自动编译/发布 | 构建workflow已编写 | 本轮未推送、未运行云端；未生成公开Release |

后续优先补：遥控器逐页验收与TV首页可见性、插件兼容/源更新、字幕与弹幕、直播体育和网盘，再接入经兼容性确认的PC发布触发。不能仅修改版本号就宣称PC新功能已自动移植。
