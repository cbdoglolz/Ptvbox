# 0.2.0 已知边界

1. 本轮没有真实机顶盒或手机实测；ATV APK不等于原生手机UI。软件GPU上的慢帧仍明显，性能验收未通过，不宣布流畅性问题完全解决。
2. 完整播放器图标栏、分层返回、全屏比例、返回系统首页后保存并停止/释放及独立后台开关属于0.3.0。当前退出到系统后台仍保存并暂停，不是后台服务。
3. 部分资源站会返回合并季、缺失年份或不完整目录。这里只展示有来源的返回，不把多来源条目总数当作权威集数；旧数据被v1主键覆盖的内容无法凭空恢复。
4. `migration_issues`保留歧义旧记录，目前没有专门的人工恢复页面。旧深链只有唯一别名时自动解析；无法分辨的类型不会猜测。此类记录原表与私有备份均保留。
5. 收藏和观看状态独立持久化。清除状态不会删除历史；已看整剧隐藏继续观看但不批量抹掉每集进度。未知编号保留来源独立身份，尚无跨站手动校正目录编辑器。
6. 首页有运行期分组缓存和已存作品回退，尚无完整持久化的各提供方/各栏目离线索引。网络失败时不能承诺每一行都有内容；Netflix不使用泛豆瓣缓存冒充标签结果。
7. 演职人员和相关作品只展示提供方真实返回；豆瓣相关作品接口本轮未新增。TMDB真实Key与人物头像没有本轮真实Key验证，仍需用户配置后检查。
8. Jar/JS/Python、国际/动画适配器、网盘扫码、在线字幕/校时、弹幕、直播体育、HDR手动映射和源更新激活尚未完成ATV迁移，PC功能不受本轮修改影响。
9. 语音依赖设备系统识别服务；拼音首字母主要检索已缓存片名。所有真实片源稳定性、长时间续播/定时/重启均未穷举。
