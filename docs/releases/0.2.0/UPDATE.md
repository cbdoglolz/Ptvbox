# Ptvbox 0.2.0 本地测试版

日期：2026年11月20日。versionCode 2，包名 `com.cbdog.ptvbox`，沿用0.1.0签名。本轮是用户批准开发后的真实程序改版；阶段0审计文件保留原始时间口径。

## 本轮实现

1. **用户数据v2**：作品和单集分配稳定UUID，外部键加入媒体类型；收藏与想看/在看/已看分开，观看状态可清除。已看完整电影与已看单集不混为整剧完成。
2. **无损迁移**：旧表保持原样，先保存应用私有备份，再在事务中迁移。保留整数毫秒，通过十进制秒接口导出；歧义身份、坏JSON留在旧表并记入待核对记录，不猜测合并。特别篇及未知编号条目按来源区分。
3. **后台读写**：新增用户Repository和不可变状态快照；收藏、历史、进度不在Compose绘制时查询SQLite。每3秒采样保留，串行写入，不再通过全局revision触发整页资料刷新。冷启动续播先等待用户资料加载。
4. **电视首页**：72dp图标栏、260dp覆盖导航；内容宽度不因展开菜单改变。首页改为继续观看、最新剧集、最新电影、热门推荐、动漫专题横排。Netflix标明豆瓣标签资料来源。
5. **继续观看**：画面、进度条、季集、已看时间和剩余时长；续播、隐藏、已看分别操作。隐藏不会删除历史。收藏及观看状态在详情和海报间同步。
6. **独立详情目录**：进入详情后并行加载资料与资源站目录，尚未播放也能看到集数，不依赖TMDB Key。支持部分结果、来源分组、刷新、缓存和取消旧请求；只进入详情不会创建播放媒体。
7. **详情展示**：背景图优先、海报回退；真实演职人员资料及TMDB相关推荐存在时才显示。没有单集评分时不套用整剧评分。
8. **兼容保护**：保留32个默认来源及其key、年份/季集匹配、20路探测、播放器、音量和音轨偏好、Keystore、8类ATV频道定义。旧首页深链增加兼容别名；Watch Next更新复用旧记录，避免同作品重复卡片。
9. **排版与焦点**：移除播放页外层内容留白；独立保存页面滚动状态，详情返回恢复原行/作品，进入详情先聚焦返回按钮。基础播放器控制仍沿用0.1.0，本轮没有提前重写0.3.0播放器。

## 验证结果

- 16个JVM测试通过；Android真实SQLite合成库升级、重复打开、毫秒往返、类型冲突、坏记录、事务失败回滚等12项检查通过。
- 独立Android TV API30 x86模拟器，无个人密钥：真实《西游记》读取播放前目录、选集起播，Media3报告实际首帧、960像素高视频及前进的播放位置。返回详情及浏览保留播放。
- 模拟器创建6类无需Key的系统频道，各20部；旧Watch Next记录复用原行，完成后删除通过。
- 签名APK从0.1.0直接覆盖安装到0.2.0并启动成功。包名与原签名一致，32个默认源内容未变，发布包没有调试测试入口、用户数据库、私有地址或签名私钥。
- 进行了200次方向键导航采样，但软件GPU上的帧指标未达成流畅性验收，不能宣布性能达标。具体结果见性能报告。

## 交付边界

这是**ATV测试APK**，可供手动传到手机试用；它不是后续原生触屏手机版。此次没有连接或操作真实机顶盒，没有上传GitHub、发送推送或修改Windows PCBOX。

完整播放器返回状态机、返回系统首页后停止并释放资源、后台播放开关等按既定0.3.0继续；当前系统离开行为仍是保存并暂停。Jar/JS/国际源、在线字幕、弹幕、直播体育和网盘等待资源专项，不能称为PCBOX完整移植。

## 安装

APK位于 `D:\Ptvbox\artifacts\release-v0.2.0\Ptvbox-0.2.0.apk`。Android 8.0及以上，横屏TV界面。已有0.1.0时直接覆盖安装，**不要先卸载或清空数据**。首次打开自动迁移，失败不会重建空库。安装v2后不要直接降级旧APK访问新数据库。
