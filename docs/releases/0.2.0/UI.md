# 0.2.0 界面变化

- 左栏固定72dp；260dp导航以独立覆盖层打开，内容约束宽度不变化。图标绘制居中，未聚焦保持白色，聚焦紫色底。
- 首页纵向内容区配横向海报行；无继续记录则隐藏该行。分类页保留网格、加载更多与原搜索入口。
- 继续观看卡片单独排布图片、进度、时间、续播/隐藏/已看，操作不覆盖标题和时间。
- 详情采用背景/海报/文字信息区、独立收藏和三态、来源目录与多列选集；没有可靠人物或相关作品时隐藏相应模块。完整单集海报、单集评分留待下一轮。
- 页面滚动位置按screen/provider/kind/category保留；海报记录行和作品key，详情返回请求恢复。进入详情默认聚焦返回按钮。Drawer用Dialog隔离遥控器焦点，返回关闭后回到内容区。
- 播放页移除外层18dp内容边距，其内部原控制栏仍保留，完整播放器重构没有提前实施。
